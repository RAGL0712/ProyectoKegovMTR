¿Cómo funciona el sistema?

El sistema usa 4 sensores Sharp GP2Y0A21YK0F montados frente a cada rueda simulada. Emiten un haz infrarrojo y miden la distancia por triangulación, entregando una señal analógica proporcional a la distancia (10–80 cm).

El Arduino MEGA lee las 4 señales a 100 Hz, clasifica el estado de cada sensor y envía un JSON por puerto Serial. Un script Python retransmite esos datos a esta página por WebSocket, logrando visualización en tiempo real sin necesidad de refrescar.

Estados de los Sensores

Estado Condición Criterio de detección
INICIANDO Calibración inicial Primeras 50 muestras — establece baseline
GIRANDO Rueda girando normalmente Variación cíclica ≥ 80 ADC respecto al baseline
RIN PLANO Sensor funcional, sin rotación Valor constante en zona de rin por más de 2 s
FALLA Sensor defectuoso Valores fuera de rango físico o σ > 120 ADC

Flujo de Datos

  • 4× Sharp GP2Y0A21YK0F conectados a pines A0–A3 del Arduino MEGA
  • Arduino muestrea a 100 Hz con temporizador sin delay() y clasifica por rangos ADC
  • Salida: JSON por Serial USB a 115200 baud cada 10 ms
  • abs_bridge.py lee el Serial y retransmite por WebSocket (ws://IP:8765)
  • Esta página se conecta al WebSocket y actualiza la UI en tiempo real
